# LinkedIn Content Intake

The official NICE LinkedIn company page is a supporting factual source, not an
automatic publishing feed.

Source: `https://in.linkedin.com/company/n-i-c-e-solutions`

## Editorial Rules

- Create source-derived project records as WordPress drafts.
- Paraphrase concise factual information; do not copy captions or hashtags.
- Store the source URL, a private source note, and an approval status.
- Never download or republish LinkedIn photographs automatically.
- Client names, dates, locations, results, team names, and media require NICE
  approval before publication.
- Migration reruns never overwrite an editor's draft or publish a record.
- Do not create public Team records from LinkedIn employee listings.
